How it works

PMV & PPD

Both sensors are computed using the ISO 7730 Fanger PMV formula implemented directly in Home Assistant's Jinja2 template engine. The clothing surface temperature is found by fixed-point iteration (100 steps) using Jinja2's namespace pattern for mutable loop variables. No network request is made.

  • PMV — Predicted Mean Vote, −3 (cold) to +3 (hot); ASHRAE-55 comfort zone is −0.5 to +0.5.
  • PPD — Predicted Percentage Dissatisfied (%); LEED compliance target is < 10 %.
Relative Humidity

Derived from dry-bulb + dew-point using the Magnus formula, or from dry-bulb + wet-bulb using Sprung’s psychrometer equation. Both run as Jinja2 template sensors — no external service needed.
