How it works

PMV / PPD sensors

Home Assistant periodically calls the /api/v1/comfort/pmv endpoint of this tool, passing the current values of your chosen sensors as query parameters. The response contains both PMV and PPD, so a single HTTP call creates two sensors.

  • PMV (Predicted Mean Vote) — scale from −3 (cold) to +3 (hot); ASHRAE-55 comfort zone is −0.5 to +0.5.
  • PPD (Predicted Percentage Dissatisfied) — percentage of occupants likely to be thermally dissatisfied; LEED compliance requires PPD < 10 %.
Relative humidity sensor

If your weather station or temperature probe provides dry-bulb and dew-point (or wet-bulb) temperatures rather than relative humidity directly, this sensor uses the Magnus formula to compute RH entirely inside Home Assistant — no external API call required.
